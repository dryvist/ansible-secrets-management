# Generated app secrets

`defaults/main/01c-app-secrets-generated.yml` is the catalog for random
credentials created once at their app path. Existing values are retained
unless the role's explicit rotation or field-validity rules require a change.
Each map entry also gives the `apps` AppRole read access to that app path.

## Hindsight

The Hindsight entry contains the dedicated database credentials, Control Plane
access key, router key, and API bearer key. Its `etcd_root_*` and
`patroni_*` fields serve the optional Patroni/etcd mode in the app's Postgres
cluster. The Postgres role reads them in `defaults/main/03-patroni.yml`; they
remain unused while the cluster uses native mode. Patroni's scoped etcd
identity is per cluster and is generated by the Postgres role at
`secret/etcd/<postgres_ha_scope>/rw`, rather than in this app map. The
`hindsight_api_key` is shared by the service, its clients, and the Control
Plane as the API bearer credential.

## AI session history

The `ai-sessions` entry contains one read-only and one read-write secret for
each vendor bucket. A writer can access only its own bucket. The fixed access
key IDs (`ai-sessions-<vendor>-{ro,rw}`) are created as RustFS users from the
generated values. App-namespaced fields keep these credentials distinct in
the flat `bao_apps_secrets` merge.
